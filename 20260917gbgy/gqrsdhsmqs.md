# 【沧州二院】基层培训开启“云端”远程新模式

> 更新时间：2026-09-17 (UTC+8)

**“云端”**

远程基层培训

为提升基层医疗水平，切实加强基层医院医疗服务能力。4月26日下午，沧州中西医结合医院对孟村中医医院全员和南皮县中医院心内二科开展线上远程心肺复苏术三级培训。

图 / 孟村中医医院医护人员正在参加远程基层培训

图 / 急诊科贾世浩讲解心肺复苏的规范和要点

图 / 南皮县中医院心内二科医生正在参加远程基层培训
