# 【关注】孩子总是睡不好，快来试试这个神奇的“儿童睡眠监测”

> 更新时间：2026-09-17 (UTC+8)

很多家长说孩子睡眠质量不太好，睡觉时打呼噜、张口呼吸、憋气、辗转不安、反复肢体抽动、尿床，甚至会呼吸暂停。白天又容易犯困，影响正常的学习和生活。睡不好的宝宝建议做个睡眠监测。

儿童睡眠监测的医学全称是：儿童多导睡眠监测。通过睡前在宝宝身体接上各种电极片（类似于做心电检查，部位会更多些），收集一晚的呼吸、血氧含量、睡眠深度等数据，然后运用科学分析得出睡眠有什么问题，严重到什么程度。

**儿童睡眠监测能分析哪些？**

1.睡眠深度：

可分析宝宝当晚睡的怎么样，有多少深度睡眠，简单来说就是睡得香不香。对于打鼾的孩子来说，睡眠越好，可能打呼噜就越明显。而对失眠患者，睡眠深度的分析能良好的反映孩子的真实情况，而不是依靠孩子的主观描述。

2.呼吸状况：

通过监测可以判断宝宝睡眠中有无呼吸暂停，以及深层次的分析呼吸暂停是不是气道阻塞或呼吸中枢受损引起的。 

3.肌肉活动状况：

有助于医生判断睡眠深度以及评估有无不宁腿综合征等疾病。

4.心电图：

可发现睡眠时发生的心脏异常。

5.血氧饱和度：

监测一晚血液内氧含量的变化，能够判断憋气的严重程度。 

**哪些情况需要做睡眠监测？**

当宝宝有以下症状时，建议带宝宝来做睡眠监测。

**儿童白天出现以下任何症状：**

1.晨起时头痛

2.感到非常疲倦

3.在上课或短途乘车等不适宜的时间睡着

4.难以专注学习

5.张口呼吸

6.脾气暴躁易怒

**儿童夜间出现以下任何症状：**

1.打鼾超过每周3天

2.睡眠期出现反复肢体抽动

3.呼吸困难

4.呼吸停顿或突然出现喘息

5.张口呼吸

6.睡眠不安或辗转反侧

7.大量出汗

8.尿床或常起夜小便

9.梦游或夜惊

10.睡眠节律紊乱

**睡眠监测如何做？有伤害吗？**

在宝宝入睡前，医护人员会在头部、胸部和腿部贴上小的粘性“电极”，类似做心电图，鼻下放置一根小管，可能还会在胸部缠上1-2条束带。上述每个部件都有导线与监测仪相连，监测仪在孩子睡眠期间记录动作、脑活动、呼吸和其他身体功能。

睡眠监测所采取的信号都是人体发出的，没有任何辐射，因此检查对人体没有伤害，家长们大可放心。

**家长要做些什么准备？**

需要监测宝宝夜间大约10-12个小时的睡眠。为了能让患儿更好地熟悉环境，我们建议下午入院。在入院当天不要午睡；检查当晚少进水及流食；为患儿洗头；避免在下午或晚上饮用咖啡、茶、汽水和其他含咖啡因的饮料。可以带上平时喜欢抱着入睡的玩具，可以带上自己的睡衣，可以带上自己平时喜欢用的枕头床单。总之尽量让宝宝舒适到接近在家睡觉的状态。检查完成后第二天一早，就可以出院回家了。
